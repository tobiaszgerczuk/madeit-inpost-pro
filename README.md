# MadeIT InPost Pro

Paid add-on for the free [MadeIT InPost](https://github.com/tobiaszgerczuk/madeit-inpost) plugin. Sold at https://labs.made-it.pl. Hooks into the free plugin through its `madeit_inpost_*` filters and actions; the licence and updater live here, never in the free plugin.

Release: bump `Version` in `madeit-inpost-pro.php`, add a `## X.Y.Z` section to `CHANGELOG.md`, push a `vX.Y.Z` tag. The workflow builds the ZIP and publishes it to the shop.
